# UNIDADE MVT

Site estático do movimento UNIDADE. A página publicada é `index.html`; os estilos e as interações ficam em `assets/site.css` e `assets/site.js`.

## Proposta visual — setembro de 2026

A abertura apresenta a assinatura “Até sermos um”, fotos do movimento em camadas e dois traços que se encontram. A proposta usa Montserrat, violeta, branco, preto e amarelo. As imagens acompanham a rolagem, e a composição de entrega apresenta as fotos quando entra na tela. A navegação, as imagens originais, os flyers, as datas e os links foram preservados.

O botão “Pausar movimento” interrompe as animações contínuas e o vídeo. A preferência de movimento reduzido do dispositivo é respeitada. O menu móvel aceita Escape e mantém o foco nos seus controles; o carrossel aceita setas, teclado e gestos e atualiza o download para o flyer selecionado.

O favicon usa o arquivo original `favicon-und.png`. A fonte é servida localmente; sua licença está em `assets/fonts/OFL.txt`.

## Revisão e publicação

O site não exige instalação ou build. Para uma revisão local, sirva esta pasta com um servidor HTTP estático. No GitHub Pages, mantenha os arquivos na raiz do projeto e publique a branch configurada no repositório.

Esta proposta foi preparada em `feat/unidade-visual-motion`. Os recursos, a sintaxe, o menu, o carrossel, os downloads e os controles de movimento foram verificados. A revisão visual em navegador e a publicação ainda precisam ser concluídas; o navegador do ambiente bloqueou a prévia local e as ferramentas de edição do plugin GitHub não estavam disponíveis.
